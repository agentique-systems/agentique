preparation gesture. It is not a claim of real journey completion or alpha acceptance.

  Explicitly leaving an agent view restores the operator's preferences first.

  package-boundary policy, including candidate views and reprojection. The
  eight-hop limit no longer falls through to a smaller local neighborhood.

  Default focus frames nearby changes in existing coordinates, after the current
  viewport size is known. Explicit navigation wins over pending automatic focus.
  Refiltering the same comparison does not automatically recenter it.

  cancellation reissues it against Current. Request IDs, view definitions and
  revision/lifecycle fences remain independent. Stale responses cannot retire a
