1. OMG Issue

KERML11 — FeatureReferenceExpression without a referent

  • Key: KERML11-182
  • OMG Task Force: Kernel Modeling Language (KerML) 1.1 RTF
Open Closed All
  • Key: KERML11-182
  • Status: open  
  • Source: Model Driven Solutions ( Mr. Ed Seidewitz)
  • Summary:

    In 7.4.9.2 Operator Expressions, it states "The classification operators may also be used without a first operand, in which case the first operand is implicitly Anything::self". However, according to 8.2.5.8.1 Operator Expressions, production ClassificationExpression, a classification expression without a first operand on the surface is actually parsed as having a first operand that is a feature reference expression with no referent. However, there is nothing in abstract syntax 8.3.4.8.5 FeatureReferenceExpression to indicate that a feature reference expression with no explicit referent is supposed to default to Anything::self.
