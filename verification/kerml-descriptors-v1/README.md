# KerML Root/Core descriptor milestone

Implemented on `foundation/kerml-descriptors-v1`, based on merged main
`ec6e84f`. [ADR 0003](../../docs/adr/0003-normative-root-core-descriptors.md)
contains exact normative evidence, all generated class counts, the canonical
association decision and remaining obligations.

The generated slice has **29 classes, 196 properties (146 class-owned and 50
association-owned), 80 binary associations and two enumerations**. It contains
46 redefinition references, 135 subset references and all three normative derived
unions. The closure resolves every structural reference without importing the
entire metamodel into the runtime. The
[golden manifest](../../standards/generated/kerml-1.0/root-core.golden.json)
lists each exact class/property identity and source fact.

Kernel additions are generic property redefinition/subsetting, association-owned
ends and opposite linkage, derived-union metadata, package-aware class naming,
and identity-based enum domains. Effective property resolution removes replaced
ancestor slots and rejects unresolved inherited conflicts. No KerML rules or class
names enter the kernel.

Both non-derived ends of the two ownership pairs are preserved. The chosen future
contract is a single logical association link with endpoint-specific ordering;
inverse indexes can provide the opposite view without duplicate canonical slots.
This milestone deliberately rejects non-derived association slot writes until
that storage contract is implemented. Derived slots remain overlay-only. There
is no universal authoritative left/right end and no guessed MOF composition.

[results.json](results.json) records actual commands, timestamps, duration, exit
status and log paths. `npm.cmd` is the Windows executable for the reported npm
commands. Logs use UTF-8/LF with trailing whitespace normalized; the first capture
used Windows PowerShell native-stderr formatting, so `NativeCommandError` labels
around Cargo progress are shell formatting, not failed command exit statuses.
The runner now records native message text directly. Browser JSON and screenshots
are included. [source-hashes.json](source-hashes.json) identifies the implementation
and generated bytes corresponding to these checks.

Reproduce the generated artifacts in one command:

```sh
cargo run --locked --offline -p agq-metamodel-gen
```

Add `-- --check` to fail on stale IR, Rust or golden output without writes.
`powershell -NoProfile -ExecutionPolicy Bypass -File verification/kerml-descriptors-v1/run.ps1`
runs the recorded verification commands from the repository root.

There are no unresolved structural dependencies in the selected slice. Executable
constraints, default evaluation, derived unions, subset value rules, canonical
association writes, ownership/cascade enforcement, scalar JSON nullability and
cross-release identity migration remain unimplemented. No new parser, namespace
lookup, library loading, SysML, simulation or repository API behavior is claimed.

Recommended next step: implement atomic storage and edits from either end of the
two ownership association pairs, retaining per-end order, then derive ownership
views with explicit evidence. Keep the generated descriptor baseline fixed while
validating those contracts.
